Production status (as of 2026-10-05)

Domestic accident-case board

The production server collects cases from Korea's Public Data Portal (dataset 15121001) once a day. The first run stored 400 official cases, each with source, dataset version, collection time and a content hash.

Attachment metadata

Up to 40 cases a day are checked through the attachment API (15121008); only links verified as official KOSHA HTTPS addresses are shown.

Construction daily serious accidents

The construction daily API (15133935) is queried from the last 7 days and further back when publication lags. Risk reduction measures are shown when available.

Reference only

KOSHA cases appear on the event screen as "similar cases (reference)". They never change risk, create events or satisfy closure conditions; a person must review and approve before anything becomes an official record.

Field-context comparison

Structure industry, process, detailed task, location and hazard type for comparisons closer to operational context than simple keyword search.

Explain why a case is similar

Show accident-type, process, detailed-task, location and text-similarity signals behind each candidate.

Connect to the Closed Loop

Carry references into risk assessment, TBM, corrective action, Evidence and residual-risk reassessment.

Human-Authorized Review

COREON presents similar cases and matching rationale, while authorized people review relevance, make the final judgment, approve actions and close the case. Official evidence and accountable human decisions remain connected in one traceable record.
