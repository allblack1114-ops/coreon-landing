전기·통신·소방 견적 소프트웨어

공내역서를 분석해 동일 자재를 합산하고, 단가·품셈·노무비·경비를 거쳐 원가계산서와 Excel 견적서까지 만드는 흐름을 개발하고 있습니다. 도면 견적은 도면 분류와 문자 판독 단계까지 개발되었습니다.

현재 이 제품은 판매하지 않습니다. 아래 표의 '구현됨'은 개발환경에서 동작을 확인했다는 뜻이며, 고객 현장에서 검증이 끝났다는 뜻은 아닙니다. 미완성 견적은 '고객 제출 불가'로 표시되며, 결과는 반드시 사람이 검토해야 합니다.

두 가지 견적 방식

공내역서 견적 개발환경 동작 확인

  • 공내역서 Excel 업로드 → 양식 판정 → 공종·품목 확인
  • 동일 자재 합산, 원본 행 추적
  • 기준단가 1회 입력 → 같은 자재 전체 반영
  • 품셈·공량 연결 → 노무비 → 경비·제비율 → 원가계산서(수식형 Excel)
  • 판정 보류(HOLD)·단가 미입력·제비율 미입력 항목을 화면과 Excel에 표시
  • 원본 공내역서는 변경하지 않음

도면 견적 개발 단계

  • PDF 도면 업로드, 미리보기
  • 도면번호·도면 종류·공종·축척·범례 유무 분류
  • 케이블·기기 번호와 규격 표기 문자 판독(로컬 처리)
  • 판독이 애매한 항목은 자동 보정하지 않고 사람 확인 목록으로 분리
  • 아직 안 됨: 그래픽 심벌 개수 세기, 배선·전선관 길이 측정, 도면과 공내역서 자동 대응

지원 공종과 구현 상태

구분상태제한사항
전기 공내역서개발환경 동작 확인품셈 연결은 일부 품목만 가능. 연결되지 않은 품목은 판정 보류로 남음
통신 공내역서개발환경 동작 확인일부 양식은 집계표·원가 미연결
소방 공내역서개발환경 동작 확인품셈 연결 범위 제한
Microsoft Excel 재계산 확인확인 전현재는 LibreOffice 재계산으로만 확인
단가 출처고객 입력제품이 단가를 제공하지 않음. 일반관리비율·이윤율은 고객이 결정
도면 견적개발 단계위 '아직 안 됨' 항목 참조

시연 및 향후 이용 신청

현재는 시연과 향후 이용 의향만 접수합니다. 유료 이용권 판매와 결제는 하지 않습니다. 고객 공사자료는 시연 신청 단계에서 받지 않습니다.

시연 신청(이메일) 향후 이용 신청(이메일) 고객 로그인·프로젝트 화면(공개 전 준비 중)

자료 보호

  • 원본 파일은 변경하지 않고 별도 결과 파일을 만듭니다.
  • 회사(계정)별로 작업과 파일을 격리합니다.
  • 고객 단가와 공사자료는 학습·통계·영업자료에 사용하지 않습니다.
  • 도면 문자 판독은 처리 서버 안에서만 수행하며 외부 판독 서비스로 보내지 않습니다.
