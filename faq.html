QUOTE

정확히 얼마예요?

COREON Safety AX Agent는 공개 정액 가격표를 사용하지 않습니다. 현장 수, 조직·사용자 구조, 공사·사업 규모, 산업안전보건관리비 등 예산 기준, 필요한 기능, API/SSO/데이터 연동, PoC 및 지원 범위를 확인한 뒤 고객별 견적서를 제안합니다.

USERS

몇 명까지 써요?

공개 페이지에서 일률적인 사용자 상한을 약속하지 않습니다. 관리자·운영자·현장 참여자 수와 역할구조를 확인해 고객 환경에 맞는 권한·용량·운영범위를 견적에 반영합니다.

몇 개 현장까지 돼요?

단일 현장부터 다사업장까지 설계할 수 있습니다. 현장 수, 본사·현장 조직구조, 협력사 운영, 데이터 분리와 보고체계를 확인한 뒤 적용범위와 견적을 확정합니다.

INSTALL

설치가 필요한가요?

기본 Safety AX는 웹 기반 SaaS라 별도 현장 장비 설치 없이 시작할 수 있습니다. 장비·센서·Vision Edge·현장 네트워크 연계가 필요한 경우만 별도 설치·검증 범위를 정합니다.

API

API 연동하려면 얼마나 걸려요?

일괄 기간을 보장하지 않습니다. 이벤트 종류, 인증, payload, Ack/Clear, 네트워크·보안 조건을 먼저 확인합니다. REST/Webhook 읽기 연동과 SCADA·전용 프로토콜 연동은 난도가 다르므로 인터페이스 확인 후 일정·비용을 확정합니다.

연동 검토 범위 →
EHS / OT

우리 회사 EHS랑 연결되나요?

연결 가능성을 검토할 수 있습니다. COREON은 기존 EHS·SCADA·MES·WMS·CCTV·AIoT를 교체하기보다 그 신호 이후의 사람 검토, 책임, 조치, 증빙, 잔여위험, 승인종결을 연결합니다. 특정 제품 호환은 실제 인터페이스 검증 후 확정합니다.

Integration 원칙 →
PoC / PILOT

PoC는 얼마고 몇 주예요?

PoC도 정액 상품으로 공개하지 않습니다. 대상 현장, 데이터, 연동 범위, 검증 KPI, 현장지원 여부를 확인해 기간과 비용을 별도 제안합니다. 핵심은 PoC 자체가 아니라 실제 운영성과와 유상 도입 가능성을 검증하는 것입니다.

PoC 견적 상담 →
KPI

도입하면 어떤 KPI가 좋아지나요?

효과를 미리 보장하지 않습니다. 대신 사건→담당자 지정시간, 기한초과율, 조치 종결시간, 증빙 완결률, 잔여위험 재평가 완료율, 재개방·반복위험 등을 같은 기준으로 측정해 실제 개선 여부를 검증할 수 있게 설계합니다.

실제 고객 사례가 있나요?

국내 대형 건설기업 공급 수행과 미국 산업현장 유료 기술컨설팅 경험이 있습니다. 다만 이를 Safety AX 도입사례로 과장하지 않습니다. Safety AX 실증·도입 성과는 고객 동의와 검증 가능한 근거가 있는 범위에서만 공개합니다.

AI가 최종 안전판단을 하나요?

아닙니다. AI는 분류·요약·추천을 보조할 수 있지만 최종 안전판단, 위험수용과 종결은 권한 있는 사람이 수행합니다. 필수 증거·잔여위험 검토·승인 조건이 빠지면 종결을 차단하는 Fail-Closed 원칙을 적용합니다.
