경영관제를 하나로

공내역서 견적에서 시작해 계약 이후의 실행예산·발생원가·예상 준공손익까지 같은 자료로 이어서 관리하는 것을 목표로 합니다. 같은 실행원가 데이터를 대표이사·공무·현장관리자가 각자의 업무 화면으로 봅니다. 단가·노임·제비율·제출금액과 원가의 확정은 사람이 결정하며, 프로그램은 가격이나 이윤을 정하지 않습니다.

무료 체험 시작(견적)고객 로그인

현재 운영 서비스에서 쓸 수 있는 것은 전기·통신·소방 공내역 견적(베타)입니다. 함께 보이는 PC·모바일 화면은 개발 중 기능입니다.

공종별 견적

전기·통신·소방 현재 제공 · 베타

  • 공내역서 XLSX 업로드, 양식 판별, 원본 결함 진단
  • 동일 자재 합산과 회사 단가 일괄 반영, 회사 단가 장부
  • 지원 양식(조달청 소방형 계열)에서 노임·원가계산서 연결 — 베타 검증 중
  • 원본 Excel은 바꾸지 않고 별도 결과 파일과 변경 이력을 만듭니다.

인테리어 개발 중 · 운영 미제공

  • 인테리어 공내역서 품목을 2026년 건설공사 표준품셈 수록 항목과 대조해 부문·항목·개정·쪽수와 단위당 노무량을 근거로 표시합니다.
  • 품셈 항목과 명확히 매칭되지 않거나 바탕면·간격·단위 등이 불명확하면 노무량을 만들지 않고 HOLD로 둡니다.
  • 원본 공내역서의 수량·수식은 바꾸지 않습니다.
  • 노무·원가 계산(개발 중): 직종별 노무비 = 단위당 직종별 공량 × 해당 직종 노임단가 × 시공 수량. 노임은 사용자가 출처·기준일과 함께 입력하며, 노임 미입력·공량 미확인은 0원으로 계산하지 않고 HOLD로 둡니다.
  • 개발환경 시험 현황: 가공 자료로 일위대가·원가계산서 산출과 Excel 재계산 대조를 시험 중입니다. 양식에 따라 HOLD 품목이 많을 수 있습니다.
개발환경 · 가공 자료 · 개발 중 화면

인테리어 견적 작업 화면(2026-11-02, 개발환경, 기능 스위치 OFF가 기본). 가공 인테리어 공내역서 12개 품목. 근거 없는 공량·노임은 금액으로 만들지 않고 HOLD로 남깁니다. 운영 서비스에는 아직 없습니다.

실행원가 관리 개발 중

관리하는 값

  • 계약금액·변경계약 — 승인된 변경계약만 확정 계약금액에 넣습니다. 미승인 변경은 따로 표시합니다.
  • 실행예산 — 자재·노무·외주·장비·경비·예비비 버전 관리. 공무가 편성하고 경영자가 승인합니다.
  • 발생원가 — 확정된 원가만 누적합니다. 검토·확정 대기 원가는 따로 보여 주고 합계에 넣지 않습니다.
  • 잔여 예상원가 — 공종별 잔여 작업과 산정 근거를 함께 기록합니다.
  • 예상 준공원가(EAC) = 누적 확정원가 + 확정 미지급 + 잔여 예상원가.
개발환경 · 가공 자료 · 개발 중 화면

공무 담당자의 계약·예산 화면(가공 공사, 개발환경).

경영관제 개발 중

대표이사 화면이 답하는 질문

  • 어느 공사가 이익을 내고, 어느 공사가 손실 위험이 있는가
  • 계약금액 대비 예상 준공원가와 예상 이익률은 얼마인가
  • 예산을 넘었거나 확정이 밀린 원가는 어디에 있는가

실무자 화면이 답하는 질문

  • 어떤 원가가 발생했고 증빙은 무엇인가
  • 무엇을 검토·반려·확정해야 하는가
  • 예산 초과의 원인과 조치는 기록됐는가
개발환경 · 가공 자료 · 개발 중 화면

전사 현황: 관리 공사 수, 확정 계약금액 합계, 예상 준공원가 합계, 예상 준공이익, 현장별 예산 대비·이익률·위험 표시(가공 현장 4건). 근거가 부족한 공사는 HOLD로 두고 이익을 표시하지 않습니다.

개발환경 · 가공 자료 · 개발 중 화면

공사 손익: 원가 구분(확정·미지급·잔여·대기), 최초 견적·계약·승인 예산·현재 EAC 비교, 예산 초과 경고. 공정회의용 Excel·PDF에는 집계 기준일과 미확정 항목을 함께 표시합니다.

사용자별 업무 개발 중

현장관리자 입력→공무 담당자 검토→권한 있는 관리자 확정→경영자 조회

대표이사·경영자

  • 전사 현황·공사 손익·승인 대기·계약·예산 승인
  • 변경계약과 실행예산의 승인 권한

공무·견적 담당

  • 계약·실행예산 편성, 원가 검토 대기 목록
  • 본인이 입력한 원가는 본인이 검토하지 않습니다(직무 분리).

현장관리자

  • 배정된 현장만 보고 원가·증빙·잔여 예상원가를 입력
  • 스마트폰 화면에서 입력·제출

1~2인 회사

  • 회사 소유자가 켜는 "단독 승인" 옵션(기본 꺼짐)
  • 단독 처리한 원가는 화면·보고서에 "단독 확정"으로 따로 표시하고 기록을 남깁니다.
개발환경 · 가공 자료 · 개발 중 화면

공무 담당자 검토 대기: 검토 완료·반려. 확정된 원가만 누적 원가와 EAC에 들어갑니다.

개발환경 · 가공 자료 · 개발 중 화면

현장관리자 원가 입력(모바일 390px).

시연 및 이용

1. 무료 체험 가입 없음 · 가공 자료

  • 가공 공내역서로 원본 결함 진단, 동일 자재 합산, 회사 단가 반영, 금액 확인, Excel 내려받기를 직접 해 봅니다.
  • 파일을 올리지 않습니다. 체험 자료는 2시간 뒤 자동 삭제됩니다. 실제 견적 결과가 아닙니다.
  • 무료 체험은 견적 기능만 포함합니다. 실행원가·경영관제는 체험에 없습니다.
무료 체험 시작

2. 실제 공내역서 견적 승인된 회사 계정

  • 승인된 이메일로 가입한 회사는 실제 공내역서를 올려 양식 판정·결함 진단·회사 단가 장부·노임 입력·Excel 결과·견적 저장과 재조회를 이용합니다.
  • 30일 무료 체험(작업 5건)이며 자동 결제는 없습니다. 회사별로 작업이 분리됩니다.
사용 신청 고객 로그인

3. 실행원가·경영관제 시연 개발 중

  • 개발 중인 화면은 가공 자료로 화면 공유 시연만 합니다. 운영 서비스에서 직접 쓸 수는 없습니다.

개발·제공 상태

기준일 2026-11-02. 현재 제공 운영 서비스에서 이용 가능 · 베타 검증 중 일부 양식에서만 운영 제공, 검증 계속 · 개발 중 개발환경에서 가공 자료로만 시험, 운영 미제공, 공개 일정 미정

영역기능상태범위·제한
공종별 견적공내역서 업로드·양식 판별·원본 결함 진단현재 제공XLSX만 지원(xls·xlsm 미지원). 지원하지 않는 양식은 업로드 단계에서 사유를 안내합니다.
동일 자재 합산·단가 일괄 반영현재 제공이름·규격이 비슷하다는 이유만으로 같은 자재로 확정하지 않습니다. 애매한 품목은 HOLD로 남깁니다.
회사 단가 장부현재 제공장부를 고쳐도 이미 만든 견적의 금액은 바뀌지 않습니다.
원본 Excel 보호·결과 내려받기·변경 이력현재 제공원본 파일과 이전 차수 결과는 바꾸지 않습니다. 정해진 셀 외에는 기록하지 않습니다.
일위대가 재료비 원천 셀 반영베타 검증 중단가대비표·일위대가가 있는 조달청 소방형 계열에서 확인했습니다.
노임·원가계산서 연결베타 검증 중조달청 소방형 계열만 지원합니다. 노임은 고객이 출처·기준일과 함께 입력하며, 빈 칸은 0원이 아니라 미입력으로 표시합니다.
인테리어 공내역 견적·2026 표준품셈 근거 확인개발 중매칭이 불명확하면 공량을 만들지 않고 HOLD로 둡니다.
인테리어 노무·공량·일위대가·원가계산 엔진개발 중노임 미입력·공량 미확인은 0원으로 계산하지 않습니다. 제비율은 사용자가 근거와 함께 입력합니다.
실행원가 관리견적 확정본 → 공사 최초 견적 연결개발 중확정된 견적 차수만 연결하며, 연결해도 실행예산은 자동으로 만들지 않습니다.
계약·변경계약·실행예산개발 중미승인 변경계약은 확정 계약금액에서 제외합니다.
발생원가·잔여 예상원가·EAC개발 중확정된 원가만 누적합니다.
검토·승인역할별 권한·직무 분리·단독 승인 옵션·기록개발 중현장 입력 → 공무 검토 → 권한자 확정 → 경영자 조회.
경영관제전사 현황·공사 손익·현장 비교·위험 표시개발 중근거가 부족한 공사는 HOLD로 두고 이익을 표시하지 않습니다.
공정회의 Excel·PDF 보고서개발 중집계 기준일과 미확정 항목을 함께 표시합니다.
도면도면(PDF·DXF) 견적개발 중제공하지 않습니다.

확인한 견적 양식 계열: 일반 단가형, 이지테크형, 조달청 소방형(개발환경과 운영 시험, 공개·가공 자료 기준). 모든 공내역서 양식을 지원하지는 않으며, 한 양식에서 확인한 결과를 다른 양식에 그대로 적용하지 않습니다. Microsoft Excel에서의 재계산 확인은 진행 중입니다.

사용 전에 확인할 점

  • 단가·노임·일반관리비율·이윤율은 제공하지 않습니다. 고객이 입력하고 근거를 기록합니다.
  • 원본에 없는 노무량을 프로그램이 임의로 정하지 않습니다. 특정 기관의 제비율을 모든 공사에 일괄 적용하지 않습니다.
  • 원본 파일의 결함(연결되지 않은 노무비 행 등)은 경고로 알려 드리고, 고객이 확인한 경우에만 보정합니다.
  • 결과는 견적 담당자가 검토한 뒤 제출 여부를 판단합니다. 원가와 손익의 확정은 권한 있는 담당자가 합니다.

자료 보호

  • 원본 파일은 변경하지 않고 별도 결과 파일을 만듭니다.
  • 고객 단가와 공사자료는 학습·통계·영업자료에 사용하지 않으며 외부 AI로 보내지 않습니다.
