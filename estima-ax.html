전기·통신·소방 공내역 견적 솔루션

공내역서 Excel(XLSX)을 분석해 동일 자재를 합산하고, 단가·품셈·공량을 입력하면 재료비·노무비·경비를 계산해 원가계산서와 Excel 견적 결과를 만듭니다. 단가·제비율·최종 금액은 견적 담당자가 결정하고 검토합니다.

공내역서 분석→동일 자재 합산→단가·품셈·공량 입력→재료비·노무비·경비 계산→원가계산서·Excel 견적 결과

확인된 제공 범위

공내역서 견적 제공 범위

  • XLSX 업로드 → 양식 판별 → 공종(전기·통신·소방)·품목 분류
  • 동일 자재 합산, 원본 행 추적, 원본 공내역서는 변경하지 않음
  • 기준단가 1회 입력 → 같은 자재 전체 반영, 차수별 이력
  • 2026 표준품셈 근거 공량·노임 연결, 판단이 필요한 품목은 HOLD로 분리해 사람이 지정
  • 1식 품목 금액 직접 입력, 제비율 입력 → 원가계산서 수식본·계산값 Excel

공종별 확인 상태 공종마다 다름

  • 전기: 전기 내역서형은 운영 웹서비스에서, 공종별 일반형은 개발환경에서 계산·Excel 출력을 확인했습니다(가공 자료).
  • 통신·소방: 해당 양식 처리 기능은 있으나 가공 표본 계산 확인을 마치지 않았습니다. 사용 전 시연으로 고객 양식 지원 여부를 먼저 확인합니다.
  • 모든 공내역서 양식을 지원하지는 않습니다.

도면 견적 미완성 · 개발 중

  • PDF 도면의 기기·자재·규격 판독 후보 표시와 사람 보정 검토표까지 시험 중입니다.
  • 배선·전선관 길이, 심벌 수량 자동 산출과 공내역서 연계는 제공하지 않습니다.
  • 도면 견적은 견적 결과 산출 기능으로 판매하지 않습니다.

사용 전에 확인할 점

  • XLSX만 지원합니다(xls·xlsm 미지원). 모든 공내역서 양식을 지원하지는 않으며, 지원하지 않는 양식은 업로드 단계에서 안내합니다.
  • 단가·일반관리비율·이윤율은 제공하지 않습니다. 고객이 입력하고 근거를 기록합니다.
  • 품셈 적용이 불명확한 품목은 임의로 산출하지 않고 HOLD로 표시합니다. 설치조건 할증은 기본 공량과 구분해 입력합니다.
  • 결과는 사람이 검토한 뒤 제출 여부를 판단합니다.

이용 방법

  • 무료 체험(가입 없음, 가공 자료) → 상담·시연 → 사용 신청 → 승인된 회사만 실제 공내역서 견적 순서로 진행합니다.
  • 제한 공개 베타(웹, PC·모바일 브라우저): 신청서 검토 → 승인된 이메일만 가입 → 30일 무료 체험(작업 5건) 순서로 진행합니다. 승인된 신청자에게 접속 안내를 드립니다.
  • 베타 기간에는 공내역서 견적만 제공합니다. 도면 견적은 개발 중이며 베타에서 제공하지 않습니다.
  • 화면의 "오류·개선 보고"로 접수된 의견을 검토해 단계별로 개선하고 버전을 갱신합니다.
  • 무료 체험 종료 후 자동 결제는 없습니다. 유료 실증은 별도 협의·계약으로만 진행합니다.
  • 신청 시 고객 공사자료는 받지 않습니다.

화면 예시(가공 자료)

가공 계정·가공 자료 화면입니다. 실제 고객 자료가 아닙니다.

이용 경로

1. 무료 체험 가입 없음

  • 가공 공내역서·가공 회사 단가로 동일자재 합산, 원본 결함 진단, 단가 반영, Excel 결과를 바로 확인합니다.
  • 파일을 올리지 않으며 체험 자료는 2시간 뒤 자동 삭제됩니다. 가공 자료 결과이며 실제 견적 결과가 아닙니다.
무료 체험 시작

2. 실제 공내역서 견적 승인된 회사

  • 승인된 회사 계정으로 실제 공내역서를 올려 양식 판정, 결함 진단, 회사 단가 장부 반영, Excel 결과를 받습니다.
  • 지원하지 않는 양식은 결과를 만들지 않고 사유를 안내합니다. 결과는 견적 담당자가 검토합니다.
사용 신청(이메일) 승인 회사 로그인

3. 상담·시연 이메일

  • 사용 중인 공내역서 양식 유형과 공종을 알려 주시면 지원 여부를 먼저 확인하고 화면 공유 시연을 안내합니다.
  • 신청 단계에서는 고객 공사자료를 받지 않습니다.
상담·시연 신청(이메일)

자료 보호

  • 원본 파일은 변경하지 않고 별도 결과 파일을 만듭니다.
  • 고객 단가와 공사자료는 학습·통계·영업자료에 사용하지 않습니다.
  • 웹서비스는 회사(조직)별로 작업을 분리하고, 보관기간이 지난 작업은 삭제합니다.
