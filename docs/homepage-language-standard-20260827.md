# COREON 홈페이지 대외 문구 기준

## 목적
COREON 홈페이지는 기업의 공식 얼굴이다. 모든 문구는 고객의 문제를 정확히 설명하고, COREON이 제공하는 해결 방식과 확인 가능한 결과를 절제된 B2B/B2G 언어로 전달한다.

## 절대 사용하지 않는 표현
- 당신, 당신의
- 여러분
- 귀사, 귀 기관
- 무조건, 완벽, 완벽한
- 100% 예방, 사고 제로 보장
- 법적 준수 보장, 면책 보장
- AI가 최종 판단, AI가 위험성평가 자동 확정
- 검증되지 않은 예방효과·정확도·성과 수치

## 권장 주어
- 고객
- 사업장
- 현장
- 기관·기업
- 정부·공공기관
- 발주처
- 대기업
- 안전관리자
- 경영책임자
- 협력사

## 문체 원칙
1. 질문형·명령형보다 선언형을 우선한다.
2. 기술 기능보다 고객 문제와 업무 결과를 먼저 설명한다.
3. `문제 → COREON의 관리 방식 → 고객이 확인할 수 있는 결과` 순으로 구성한다.
4. 공공데이터와 AI는 참고정보 제공 역할로 한정하고 최종 판단은 사람이 수행한다고 명확히 한다.
5. 법령 준수, 사고 예방, 효과를 보장하는 표현은 사용하지 않는다.
6. KOSHA 공공데이터는 공식 재해사례 기반 참고정보라는 사실만 정확히 표현한다.
7. 기능명, 가격, 플랜명은 제품 내 표기와 홈페이지·SEO·제안서에서 동일하게 유지한다.

## 홈페이지 핵심 메시지 기준
### Hero
**현장에서 발견된 위험을 조치완료까지 연결합니다.**

위험성평가와 TBM에서 확인된 위험을 담당자·기한·개선조치·증빙·잔여위험 재확인까지 하나의 흐름으로 관리합니다. KOSHA 공식 재해사례는 현장 위험과 비교 가능한 참고정보로 제공하며, 최종 판단과 종결은 권한 있는 사람이 수행합니다.

### 고객 문제
**안전업무의 공백은 위험을 찾은 뒤 발생합니다.**

담당자 불명확, 기한초과, 증빙 누락, 반복위험, 종결 확인의 어려움을 하나의 Safety Event 흐름으로 연결해 관리합니다.

### 공공기관·대기업
**다현장·다협력사의 미조치와 기한초과를 조직 단위에서 확인합니다.**

### 건설·플랜트
**TBM과 위험성평가에서 확인된 위험을 현장조치와 재확인까지 연결합니다.**

### 제조·물류·식품
**반복되는 설비·공정·작업 위험을 개선이력과 함께 관리합니다.**

### 5인 이상 사업장
**안전전담 인력이 제한된 사업장도 위험 발견부터 조치·증빙·재확인까지 핵심 안전업무를 한 곳에서 관리할 수 있습니다.**
